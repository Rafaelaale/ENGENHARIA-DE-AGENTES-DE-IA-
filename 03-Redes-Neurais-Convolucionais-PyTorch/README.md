# Curso 03 — Redes Neurais Convolucionais com PyTorch

## Aula 01 — Motivação

Objetivos:

1. Entender imagens como matrizes de pixels.
2. Visualizar intensidades de 0 a 1.
3. Transformar imagens 2D em vetores 1D.
4. Calcular os parâmetros de uma MLP.
5. Comparar o custo de MLP e CNN.
6. Aplicar kernels de convolução.
7. Visualizar mapas de características.
8. Construir uma CNN simples no PyTorch.

## Executar

No terminal do VS Code:

    .\.venv\Scripts\python.exe aula01_motivacao.py

Os gráficos serão salvos na pasta resultados.
