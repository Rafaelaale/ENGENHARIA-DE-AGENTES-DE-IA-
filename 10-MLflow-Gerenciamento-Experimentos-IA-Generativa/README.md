# MLflow - Gerenciamento de Experimentos e IA Generativa

Laboratorios praticos desenvolvidos durante estudos na Alura.

## Tecnologias

- Python
- MLflow 3
- SQLite
- Scikit-learn
- Hugging Face Transformers
- PyTorch
- GPT-2
- Prompt Registry
- OpenAI SDK
- Python-dotenv

## Conteudos

- Rastreamento de experimentos
- Registro de parametros e metricas
- Model Registry
- Nested Runs
- Registro e versionamento de prompts
- Avaliacao heuristica de respostas generativas
- Integracao com modelo GPT-2
- Visualizacao de experimentos no MLflow UI
- Preparacao para integracao com API OpenAI

## Observacoes

A integracao com OpenAI foi preparada, mas nao houve teste
de uma chamada real por falta de chave configurada.

A perplexidade simulada e a toxicidade heuristica
utilizadas nas aulas sao demonstracoes educacionais,
nao avaliadores completos de qualidade de LLMs.

Arquivos de ambiente, bancos locais, credenciais
e pesos de modelos nao fazem parte deste repositorio.
