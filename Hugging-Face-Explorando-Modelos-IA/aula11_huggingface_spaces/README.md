# Remoção de Background com IA

Aplicação educacional desenvolvida durante a trilha
Hugging Face da Alura.

## Funcionalidades

- Upload de imagens de produtos
- Segmentação automática com inteligência artificial
- Remoção de fundo
- Exportação de imagens PNG transparentes
- Interface gráfica com Gradio

## Tecnologias

- Python
- Hugging Face Transformers
- BRIA RMBG-1.4
- PyTorch
- Pillow
- Gradio

## Modelo

briaai/RMBG-1.4

O modelo possui condições específicas de licenciamento.
Esta demonstração destina-se a aprendizado não comercial.

## Funcionamento

1. Envie uma imagem.
2. Execute o processamento.
3. Confira a imagem sem fundo.
4. Baixe o PNG.
