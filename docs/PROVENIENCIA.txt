3. ADAPTAÇÕES LOCAIS

- README principal e guias dos projetos apresentam escopo educacional, comandos,
  distinção entre modelos locais e API paga e limitações dos dados.
- Adicionados manifestos de dependências para Python 3.12. A checagem de
  advisories identificou versões vulneráveis de LangChain, langchain-community
  e PyPDF no requirements original. Os manifestos usam versões corrigidas;
  o import de prompt em main_chat.py passou para langchain_core.
- Chroma 1.5.9 foi sinalizado com vulnerabilidades sem versão corrigida.
  Por isso não foi adicionado. Nas demos executáveis de RH e medicamentos,
  Chroma foi trocado por FAISS em memória; foi removida a exclusão de diretório
  de índice do exemplo de medicamentos.
- Os caminhos das três demos em projetos/rag-langchain/projetos/ agora apontam
  para documentos/ na raiz do próprio projeto, independentemente do diretório
  de onde o script é invocado.
- Removida a desserialização pickle de índices FAISS em agente_futebol.py e
  aula_rag_pdfs.py. Os índices são construídos em memória a partir dos documentos
  incluídos. Isso troca a reutilização em disco por recriação a cada execução.
- As referências do professor foram preservadas sem reescrita e identificadas
  como históricas, fora do ambiente de execução recomendado. Os nomes originais
  e a separação entre aulas/adaptações e referências mantêm a atribuição.

4. EXCLUSÕES E LIMITES

Não foram importados .git/, .env, credenciais, ambientes virtuais, caches,
checkpoints, índices vetoriais ou modelos baixados. Os snapshots inspecionados
não continham esses artefatos; a raiz ganhou regras preventivas de .gitignore.
Nenhum .env.example foi necessário. Os PDFs/TXT são dados de estudo, não índices.

Os PDFs de RH e medicamentos são sintéticos; o material de futebol é didático.
Os documentos GTB são arquivos de estudo já presentes na fonte; não foi atribuída
autoria desses materiais ao portfólio. As referências identificadas como do
professor mantêm essa identificação. Nenhuma nova licença foi presumida.

Nenhum repositório de origem foi alterado, removido, arquivado ou teve suas
configurações modificadas. Esta operação consolida arquivos, não o histórico Git
completo dos repositórios de origem.
