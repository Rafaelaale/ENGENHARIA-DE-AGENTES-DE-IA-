# MD Bank - Agentes Inteligentes com Protocolos MCP, A2A, AG-UI e BFA

Projeto corporativo de agentes bancários autônomos baseado em arquitetura de protocolos de comunicação e supervisão:
- **MCP (Model Context Protocol)**: Servidores de contexto e ferramentas.
- **A2A (Agent-to-Agent)**: Comunicação entre agentes especialistas (Abertura de Conta, Cartão de Crédito).
- **Camada Supervisora**: Orquestração e roteamento de mensagens.
- **Interfaces**: Streamlit e React (AG-UI).
- **Infraestrutura**: Docker Compose.
