# Hugging Face - Transfer Learning para NLP

Projeto pratico desenvolvido durante estudos de Engenharia de IA.

## Tecnologias
- Python
- Hugging Face Transformers e Datasets
- DistilBERT em portugues
- PyTorch
- Gradio
- Pandas

## Implementacoes
- Pipeline experimental zero-shot
- Aplicacao Gradio inicial
- Carregamento de 4.570 redacoes
- Separacao em treino (3.656) e teste (914)
- Tokenizacao de textos com DistilBERT
- Conversao de notas para 11 classes
- Preparacao do modelo e dos lotes
- Diagnosticos de treinamento em CPU
- Codigo de publicacao no Hugging Face Hub
- Codigo de inferencia e aplicativo Gradio

## Estado de execucao
As aulas de preparacao foram validadas localmente.

Aula 10: cinco atualizacoes com AdamW concluidas.
Treinamento completo de duas epocas: pendente.

Aulas 11 e 12: codigos preparados, dependem do modelo treinado.

Aula 13: interface e validacoes aprovadas.
Predicao efetiva depende da conclusao do treinamento.
