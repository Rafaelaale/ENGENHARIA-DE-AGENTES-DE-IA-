# Hugging Face - Transfer Learning NLP

Projeto de classificacao de notas de redacoes utilizando
DistilBERT, PyTorch, Transformers e Gradio.

## Treinamento

- Redacoes para treinamento: 3656
- Redacoes para avaliacao: 914
- Classes: 11 (notas de 0 a 10)
- Epocas: 2
- Atualizacoes: 458
- Limite de sequencia: 128 tokens
- Acuracia final: 37,64%
- Loss de avaliacao: 1,6992

## Resultado

Treinamento concluido com sucesso.

O modelo ainda necessita de melhorias e nao deve ser
utilizado como corretor confiavel de redacoes.
